# VectorAccelerate against VectorCore 0.4.0-alpha.1: alpha-only upgrade rows

This file records the audit of the eleven rows that VectorCore's upgrade list (`DOWNSTREAM_UPGRADES.md`) added after the October candidate that `VECTORCORE-0.4.0-CANDIDATE.md` covers. The audit was run on the branch `gifton/vectorcore-alpha1` at the commit that adds this file (the parent of that commit is the tree that was searched; this file and the guard test `VectorCore040CompatTests/testLinkedVectorCoreIsTheAlpha` are the only changes). Every `Search run` cell is run from the worktree root. Hit counts are lines matched by that command (`| wc -l`).
